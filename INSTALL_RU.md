# Установка Block Frontier на Nokia 2720 Flip

Игра разработана **для KaiOS 2.5.x**, а не для Apple iOS и не для Android. Это **одиночная 2D-песочница**, без 3D-движка и мультиплеера.

## Где взять установочный файл

1. Открой [GitHub Actions](https://github.com/danilfg/kaiOS-runner/actions/workflows/build.yml).
2. Выбери **Build KaiOS game** → последний успешный запуск, либо **Run workflow**.
3. Скачай артефакт **block-frontier-nokia-2720**.
4. Распакуй скачанный архив **один раз**. Внутри будет файл **block-frontier-kaios.zip**. Именно он содержит приложение KaiOS с `manifest.webapp` в корне.
5. При публикации git-тега с префиксом `v` тот же ZIP добавляется в GitHub Releases.

## Перед установкой: версия прошивки

Nokia 2720 Flip: экран 240×320, 512 МБ RAM, Snapdragon 205, KaiOS 2.5.2. Игра отрисовывается Canvas 2D с ограничением примерно 20 кадров/с. Производительность на реальном аппарате ещё **не проверялась**.

**Важно:** в некоторых версиях прошивки, в частности 2.5.2.2 с `release-keys`, установку сторонних приложений могут блокировать. Не нужно перепрошивать или рутовать телефон ради игры.

## Установка через WebIDE (если разрешает прошивка)

1. На Nokia открой номеронабиратель и введи `*#*#33284#*#*` — на поддерживаемых версиях включится режим отладки. Иногда появляется значок жука.
2. Подключи Nokia к компьютеру USB-кабелем с поддержкой передачи данных.
3. Установи ADB и проверь подключение командой `adb devices`.
4. Открой совместимый с KaiOS 2.5 WebIDE (официальная инструкция рекомендует Firefox 59 или более старую совместимую сборку).
5. Распакуй файл **block-frontier-kaios.zip** в папку. В этой папке должен лежать `manifest.webapp`.
6. В WebIDE выбери **Open Packaged App**, укажи папку и нажми **Run / Install**.
7. Проверь, появилась ли игра в списке приложений Nokia.

Документация: https://developer.kaiostech.com/docs/getting-started/env-setup/os-env-setup/

Если отладка или установка недоступны, не продолжай рискованные манипуляции с прошивкой. Узнай точную версию KaiOS, затем выбирай разрешённый способ установки.

## Кнопки Nokia 2720

| Кнопка | Действие |
|---|---|
| 4 / 6 | Движение влево / вправо |
| 2 | Прыжок, в творческом режиме — полёт вверх |
| 0 | Еда, в творческом режиме — полёт вниз |
| 8 | Добыть блок |
| 5 / OK | Поставить блок / подтвердить выбор |
| 1 / 3 | Выбрать блок |
| 9 | Переключить направление действия (перед собой / вверх / вниз) |
| 7 | Переключатель / отдых |
| * | Инвентарь, рецепты |
| # | Пауза, сохранение, главное меню |

В меню выбирай пункт кнопками **2 / 8**, подтверждай **5**. Два нажатия **0** в списке миров удаляют соответствующий мир.

## Что уже есть в игре

- Несколько биомов и бесконечная горизонтальная процедурная генерация из исходного числа (`seed`).
- Добыча блоков, строительство, руда, крафт инструментов, факелов и механизмов.
- Выживание (здоровье, голод, ночные противники) и творческий режим.
- День и ночь, пиксельная 2D-графика.
- **3 отдельных мира** с локальными сохранениями и автосохранением примерно каждые 6 секунд.
- Игра полностью офлайн, **никакого мультиплеера**.

Данные сохраняются через `localStorage`, поэтому удаление приложения или его данных может стереть миры. Дальнейшее тестирование на реальном Nokia 2720 обязательно.
